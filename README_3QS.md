# 3QS 形状による核分裂の鞍点 (pes3qs, saddle3qs)

FRLDM（frldm_mod）と殻補正・対補正（shell_bcs_mod）を，P. Möller et al., *Heavy-element fission barriers*, Phys. Rev. C **79**, 064304 (2009)（以下 PRC 79）の三つの 2 次曲面（three-quadratic-surface, 3QS）の形で計算し，immersion 法で核分裂の鞍点を探すプログラムです．

1. `pes3qs.exe`：1 つの原子核について，5 次元の格子 (Q2, d, εf1, εf2, αg) の各点でポテンシャルエネルギーを計算してファイルに書きます．
2. `saddle3qs.exe`：そのファイルを読み，入口（基底状態側）から出口（大きい Q2 の谷）への一番低い鞍点を immersion 法で求めます．

```bash
bash build_3qs.sh                 # FFTW3 と LAPACK が必要（build.sh と同じ）
./pes3qs.exe pes3qs.nml           # ポテンシャル曲面
./saddle3qs.exe saddle3qs.nml     # 鞍点
./test_qs3.exe; ./test_frldm_3qs.exe; ./test_immersion.exe   # テスト
```

## 3QS 形状 (qs3_shape_mod.f90)

z 軸まわりの回転面 3 つ（左の端の物体 1，首の部分 3，右の端の物体 2）を，z1, z2 で ρ と dρ/dz が連続になるようにつなぎます（PRC 79 式 (3)）．

```
ρ² = a1² − (a1/c1)² (z − l1)²   (l1 − c1 ≤ z ≤ z1)
ρ² = a3² − (a3/c3)² (z − l3)²   (z1 ≤ z ≤ z2)     σ2 < 0 なら一葉双曲面（首）
ρ² = a2² − (a2/c2)² (z − l2)²   (z2 ≤ z ≤ l2 + c2)
```

座標は式 (4), (5) の

```
u = [(a1² + a2²)/2]^(1/2)
σ1 = (l2 − l1)/u,  σ2 = a3²/c3²,  σ3 = (a1²/c1² + a2²/c2²)/2
α1 = (l1 + l2)/(2u)（重心で決まる），α2 = (a1² − a2²)/u²,  α3 = a1²/c1² − a2²/c2²
```

です．`qs3_from_sigma(R, σ1, σ2, σ3, α2, α3)` で体積 4πR³/3，重心 z = 0 の形を作ります．

- 作り方：曲面 i の ρ² を z の 2 次式 P_i(z) とすると，z1 でなめらかにつながる条件は「P1 − P3 が z1 に 2 重根をもつ」ことで，P1 − P3 = k1 (z − z1)²，k1 = σ2 − a1²/c1² です．z2 も同じです．2 式の差 P1 − P2 = k1 (z − z1)² − k2 (z − z2)² の 1 次と 0 次の係数から z1, z2 の 2 次方程式が出ます．l1 − c1 ≤ z1 < z2 ≤ l2 + c2 で，首の部分の ρ² が正になる根をとります．そういう根がなければ形はありません（`valid = .false.`）．
- 各部分は ρ² = p0 + p1 z + p2 z² で持つので，σ2 = 0（c3 → ∞）も特別扱いしません．
- 体積，重心，四重極モーメントは多項式の積分なので厳密です．表面積 B_s（FRDM2012 式 70）は各部分で Gauss–Legendre 積分します（被積分関数は各部分でなめらか）．
- `q2_barn()`：同じ形の ²⁴⁰Pu の電気四重極モーメント [b]（PRC 79 図 2 の注と式 (14)，r0 = 1.16 fm）．Q2 = Z R² q，q = ∫(2z² − ρ²)dV/(V R²)．
- `neck_diameter()`：首の直径 d = 2 × (首の部分での ρ の最小値) [fm]．
- `b_w(a_d)`：A⁰ 項と Wigner 項の形状因子（FRDM2012 式 (75)）．σ2 ≤ 0 で B_W = (1 − S3/S1)² a_d + 1，σ2 ≥ 0 で 1．S3 は首の断面積，S1 は小さい方の端の物体（完成させた回転楕円体の体積 a²c が小さい方）の最大断面積 πa²．切断の直前で 1 + a_d になります．
- `eval(u, v, r, N)`：surface_shape としての表面の点と法線．u ∈ [0, π] を π/8 の倍数で 3 つに分けて各部分に割り当てます（potential_gh_mod のパネルがつなぎ目をまたがないように）．端の物体では極の近くで z − z_極 ∝ 1 − cos(πt/2) とするので ρ ∝ t でなめらかです．

## 5 つの形の座標 (qs3_coord_mod.f90)

PRC 79 の (Q2, d, εf1, εf2, αg) から σ, α を決めます．

- εf1, εf2：端の物体の Nilsson の ε．回転楕円体の a/c = (3 − 2ε)/(3 + ε) から σ3, α3（式 (6), (7)）．
- αg = (M1 − M2)/(M1 + M2)，M_i は端の物体を閉じた回転楕円体にしたときの体積 a_i² c_i（式 (9), (10)）．α2 は式 (11)．
- Q2：σ2 を固定して σ1 を数値的に合わせます（σ1 = 0, 0.1, … と調べて Q2 をはさむ区間を見つけ，二分法）．論文の「d, αg, εf1, εf2 の組ごとに，45 個の Q2 になるよう σ1 を数値的に決める」にあたります．
- d：Q2, εf1, εf2, αg を固定すると，d(σ2) は σ2 とともに増え，σ2 ≈ 0 付近で最大 d_max になります．それより σ2 が大きい（中央がふくらんだ）形では，最小の ρ が端の物体とのつなぎ目に来るので d はまた減ります．そこで増える側の枝 [d_min, d_max] をとり，d がその区間を n_d 等分するように σ2 を選びます（σ2 の二分法）．d_min は，σ2 → −∞（論文の「σ1 < σ1t では形の作り方が許す最小の首」）か，首がちぎれる直前（d → 0，σ1 > σ1t のとき）です．σ2 は −1000 から調べます．

論文には「15 個の σ2 を，d が最小値と最大値の間でほどよい間隔になるように選ぶ」とだけあり，d の正確な定義と間隔は書かれていません（「非常に非線形なので詳細は略す」）．上の決め方は本コードでの解釈です．格子の点の形そのものは論文と違うかもしれませんが，immersion 法は格子の番号だけを使うので，鞍点の高さは格子が十分細かければ変わりません．

既定の格子（PRC 79 図 2）は

| 座標 | 点の数 | 値 |
|---|---|---|
| Q2 | 45 | (Q2/b)^(1/2) = 2.00, 2.25, …, 13.00（論文に値がないので本コードの選択） |
| d | 15 | 各 (Q2, εf1, εf2, αg) で [d_min, d_max] を 14 等分 |
| εf1, εf2 | 15 | −0.2, −0.15, −0.1, 0, 0.1, 0.15, 0.175, 0.2, 0.225, 0.25, 0.275, 0.3, 0.35, 0.4, 0.5（式 (8)） |
| αg | 35 | −0.02, 0.00, …, 0.66（式 (12)） |

で，全部で 5 315 625 点です．形がない点（たとえば端の物体が細長いと小さい Q2 は作れない）は飛ばします．

## FRLDM の変更 (frldm_mod.f90)

- 3QS の形（`qs3_shape`）では，B_1, B_3 の二重表面積分を軸対称性を使ってリングの和で計算します（`axial_sums`）．外側の点の方位角は 1 つだけでよいので，一般の形の `surface_sums` より桁違いに速く（1 形あたり約 15 ms），つなぎ目で曲率が飛ぶことによる誤差もありません（各部分で別々に Gauss–Legendre 点をとります）．子午線に沿った点の間隔は球で n 点のときと同じにし，B_1 は n と 3n/2 の Richardson 外挿です．B_3 は被積分関数がなめらかなので n/2 点です．
  - 球：B_1 の誤差 3.6e−5，B_3 の誤差 4e−11（n = 64）．
  - 3QS の例で n = 64 と 128 の差は B_1 で 4e−5（E_s で約 0.03 MeV），B_3 で 6e−8 です．
- B_W は 3QS の形では FRDM2012 式 (75)（上の `b_w`，a_d = 0.9）です．E_a0 = a_0 B_W，E_W = W(|I| B_W + …) に入ります．ほかの形ではこれまでどおり 1 です．
- 定数は FRDM2012 の FRLDM の値（frldm_mod）のままです．PRC 79 は FRLDM の 2002 年のパラメータを使っているので，同じ値でない可能性があります．

## 殻補正・対補正 (shell_bcs_mod.f90)

`shell_bcs_calculation(..., qs3=s, n_basis=nb)` で 3QS の形の一粒子ポテンシャルを使います．

- 形は半径 R_pot に拡大縮小します（`scaled`）．
- 振動子基底は，同じ体積と四重極モーメントをもつ回転楕円体（半軸 a, c）に合わせ，ħω_z = ħω0 R/c，ħω_⊥ = ħω0 R/a とします．
- αg ≠ 0 または εf1 ≠ εf2 では z の鏡映対称性がないので，ポテンシャルを全部の求積点で計算します．
- 1 形あたり（1 スレッド）z の鏡映対称な形で約 10〜20 秒，非対称な形で約 45 秒かかります（²⁴⁰Pu，Q2 = 42 b，n_gh = 44）．²⁴⁰Pu で n_basis = 12 と 14 の E_s+p の差は Q2 = 12 b で 0.07 MeV，Q2 = 42 b で 0.03 MeV でした．細長い形では n_basis を増やして確かめてください．
- 論文は，近くの核で同じ一粒子準位を使い回して計算時間を減らしていますが，本コードは形ごとに一粒子準位を計算します．

## pes3qs.exe

入力は namelist `&pes3qs_input` です（ファイル名を引数で渡します．既定は pes3qs.nml）．

```
&pes3qs_input
  Z = 94, N = 146,
  sqrtq2_min = 2.0, sqrtq2_step = 0.25, n_q2 = 45,   ! (Q2/b)^(1/2) の値
  n_d = 15,
  n_eps_f = 15, eps_f = -0.2, -0.15, -0.1, 0.0, 0.1, 0.15, 0.175, 0.2, 0.225, 0.25, 0.275, 0.3, 0.35, 0.4, 0.5,
  alpha_g_min = -0.02, alpha_g_step = 0.02, n_alpha_g = 35,
  same_eps_f = .false.,   ! .true. で εf2 = εf1 だけ（4 次元）
  micro = .false.,        ! .true. で殻補正 + 対補正も計算する
  n_gh = 44, n_basis = 12, pairing = 'LN',
  n_quad = 64,            ! B_1, B_3 の点の数
  out = 'pes3qs.dat',
  restart = .false.       ! .true. で out にすでにある (Q2, εf1, εf2, αg) を飛ばす
/
```

- 出力は 1 行 1 点で，列は iq, id, ie1, ie2, ia（格子の番号），ok（形があれば 1），Q2 [b]，d [fm]，d/R，εf1，εf2，αg，σ1, σ2, σ3, α1, α2, α3，B_s, B_1, B_3, B_W，E_mac − E_mac(球)，E_s+p，E_pot [MeV] です．エネルギーはすべて球の巨視的エネルギーからはかります（論文と同じ）．
- (Q2, εf1, εf2, αg) の組ごとに OpenMP で並列に計算します（`OMP_NUM_THREADS`）．
- 計算時間（巨視的エネルギーだけ，4 スレッド）：1 形あたり約 3 ms．全格子（530 万点）で約 5 時間です．`micro = .true.` では 1 形あたり 10〜45 秒なので，全格子は計算機クラスタが必要です．まず same_eps_f = .true.，αg = 0 などで次元を減らして試してください．

## saddle3qs.exe

```
&saddle3qs_input
  file = 'pes3qs.dat',
  energy = 'pot',             ! 'pot'（E_pot）または 'mac'（巨視的エネルギーだけ）
  entry_point = 0, 0, 0, 0, 0, ! 入口の格子番号 (iq, id, ie1, ie2, ia)．0 なら iq <= entry_iq_max の最低点
  entry_iq_max = 1,
  exit_point = 0, 0, 0, 0, 0,  ! 出口．0 なら iq >= exit_iq_min（既定は最大の Q2）の最低点
  exit_iq_min = 0,
  noise = 0.001, seed = 20090601,  ! 各点に足す乱数 0.001 R MeV（R は [−1, 1] の一様乱数）
  n_saddles = 1,              ! 2 以上でダム法による次の鞍点も探す
  path_file = 'saddle3qs_path.dat'
/
```

### immersion 法 (immersion_mod.f90)

論文の方法（III.B–III.E 節）は，入口に水を入れて水位を少しずつ上げ，「水位より低く，隣（各座標を 1 つずらした 2×5 点）が濡れている点を濡らす」を変化がなくなるまで繰り返し，出口が濡れた水位を鞍点の高さとするものです．刻みを細かくしていって，出口へ水が流れ込む直前に最後に濡れた点が鞍点です．

刻みを 0 にした極限では，点 j が濡れる水位は L(j) = min_{入口から j への道} (道の上の E の最大値) です．本コードはこれを優先度つきキュー（ダイクストラ法の「+」を「max」にしたもの）で正確に求めます．出口が濡れる水位 L(出口) が鞍点の高さで，水が出口へ届いた道の上で E が最大の点が鞍点です．論文と同じく，鞍点を一意にするため各点に 0.001 R MeV の乱数を足します．test_immersion で，論文どおり水位を刻んで上げる方法と同じ鞍点になることを確かめています．

- ダム法（III.E 節）：見つけた鞍点のエネルギーを 1000 MeV にして探し直します．新しい鞍点がダムの隣なら水がダムを回り込んでいるだけなので，その点もダムにします．ダムの隣でない鞍点が出たら，それが次の鞍点です．
- 鞍点を通る水の道（入口から出口まで）を path_file に書きます．道に沿った E は核分裂障壁の曲線の目安になります（論文の「最適な道」とは限りません）．

### 例：²⁴⁰Pu の巨視的エネルギー（対称な形だけ）

```
&pes3qs_input
  Z = 94, N = 146, same_eps_f = .true., alpha_g_min = 0.0, n_alpha_g = 1, out = 'pu240_sym.dat'
/
&saddle3qs_input
  file = 'pu240_sym.dat', energy = 'mac'
/
```

45 × 15 × 15 = 10 125 点（形があるのは 8 902 点）で 33 秒（4 スレッド）．巨視的な鞍点は Q2 = 45.6 b，d/R = 1.45，εf1 = εf2 = 0.25 で，E_mac − E_mac(球) = 3.91 MeV でした．

## 確かめたこと

- test_qs3：体積・重心・z1, z2 での ρ と dρ/dz の連続性，εf1, εf2, αg が入力どおりになること，Q2 と d が目標どおりになること，(εf1, εf2, αg) と (εf2, εf1, −αg) が鏡映の同じ形になること，eval による一般の面積分と厳密な体積・表面積が合うこと．
- test_frldm_3qs：球のリング和が FRDM2012 式 (74) と合うこと，3QS の B_1, B_3 の収束，一般の二重表面積分（つなぎ目のため収束が遅い）との比較．
- test_immersion：2 次元の 2 つの峠をもつ曲面で，水位を刻んで上げる方法と同じ鞍点になること，ダム法で 2 番目の峠が見つかること，5 次元の曲面で鞍点の位置が正しいこと．

## まだしていないこと

- 論文の値（鞍点の高さ）との比較．論文の障壁は E_mac + E_s+p を 5 次元の全格子で計算したもので，ε パラメータ化・β パラメータ化の結果とも比べて低い方をとっています．
- 一粒子準位を近くの核で使い回す高速化（論文 II.B 節）．
- 3QS で表せない基底状態（ε4 など）は，main.f90 の ε パラメータ化で求めてください．
